# AWS Getting Started with Terraform

A practical learning project based on HashiCorp's AWS Getting Started tutorials.

## What I practised

- Creating an EC2 instance and VPC networking in eu-west-2.
- Using input variables and output values.
- Reusing the Terraform AWS VPC module.
- Migrating local state to HCP Terraform.
- Running Terraform remotely through HCP Terraform.
- Reviewing infrastructure and planning resource cleanup.

## Scope

This is a training environment, not a production deployment.
The configuration is adapted from HashiCorp's tutorials.
